# 固定矿山雷达：时序特征、对照与探针的预声明

这份文档定义算法并记录已实际运行的输入检查。预测结果须以成功完成的 197 训练收据和评价表为准；本文件不把本机特征检查当作训练或性能验证。

## 当前域和单位

- 历史只允许通过清单中 T0 检查的公开矿山静态序列。序列内按真实导出序号向后取最多 9 个连续过去观测；没有给序号补造秒时钟。关闭 Carén 未认证配准、当地导出云与原始 bag 的跨域历史输入。
- 同一帧的每个有效 XYZI 均可算单帧特征。训练池是每中心最多 2,048 个均匀有效已标点，每种子从同一池独立选最多 1,024 个；14 个配方在一个种子上共用完全相同的当前点。验证/探索性评价处理整帧，非有限输入为 NaN，不参与指标。原索引保存为读入值，不用近邻重建身份。非监督点可作点云上下文。
- 采用 0.10、0.30 的处理坐标体素与 0.60 的区域，不称米。在 train 三个录制各取一个已有中心，局部 8 邻距离中位数的第 95 分位为 0.0556、0.0721、0.0633，帮助说明这些尺度相对真实点间距的大小；未使用测试集或统一假定公共坐标与本地物理尺度相同。点数、体素统计都不是透射率或浓度。

## 定义

静态特征 S 共 12 维：处理坐标 XYZ、距离、asinh 强度、两尺度 log(1+点数)、局部最多八个支持点的邻距中位数/最大值及三个协方差特征。全云建立近邻、体素和区域点矩；选择训练点不会改变空间上下文。

用 q=1-exp(-n/3) 表示一个体素在本次扫描的观测支持。历史与当前的可比条件是历史处理云包围范围内（细尺度余量）且区域有观测；窗口需含最近可比帧且有至少 min(3,实际长度) 个可比观测。它是处理空间覆盖的**近似**，不是已知激光射线。visibility=0 为无效当前点，1 为超出历史观测包围范围，2 为静态数据无合格历史，3 为非 T0/未认证运动补偿，4 为范围内缺足够观测，5 为可比；校准视场外和真实遮挡无法通过这些数据独立确认，不并入自由空间。

| 组 | 可复算证据 | 局限 |
| --- | --- | --- |
| F0 | 当前减去过去帧最近邻的三轴差值、模长、最多 4 个邻点的中位距离、asinh 强度差及可用性 | 不是流速；未使用作者 diff/flow/插值，也非论文网络完整复现 |
| F1 | 两尺度出现比例、最近三次与全窗差、末帧至当前的正/负支持变化、有可比缺口后的再次出现、软交并和相邻更新比例 | 统计的是当前点位置附近观测记录变化，不检测物质生灭 |
| F2 | 由最近两个过去帧在固定区域内估计中心平移，预测当前；局部点数不足、协方差退化或超过限幅即无效。前向当前点到平移后历史、逆向历史支持到当前，计算截断残差、前后覆盖、相对静态解释的改善与退化掩码 | 平移是局部刚体假设的特例，非完整六自由度刚体跟踪；逆向包含该区域的历史点，不仅选中与当前配对的点。粗分区可将不同表面混合，残差小不是实体认证 |
| F3 | 束缚在同一 0.60 区域的协方差尺度、中心预测误差、归一化谱差、可定向时的法向夹角余弦、平移后共同支持 min(q_current,q_previous)、外围更新幅度 | 点数门与 F2 配合，支持的是局部固定区域形状。对边界裁剪与转动敏感；没有恢复物理实例 |
| F4 | 过去三帧拟合：前两帧预测第三帧，比较平移后的细格支持 b 与六轴邻格平均 a。系数 alpha=clip(mean[(a-b)(target-b)]/(mean[(a-b)^2]+0.02),0,0.5)。随后以最近帧及过去预测的局部平移在**当前留出帧**比较 abs(q-b) 与 abs(q-b-alpha(a-b))，记录残差差、混合强度、预测变化与拟合稳定度 | 这是受限平滑的观测预测；不声称物理扩散系数，不给泛化结论。当前点查询仅覆盖有观测的位置 |
| REC | 有限窗，以 0.7^lag 对可比细尺度支持加权，记录加权支持/更新、最近支持滞后、加权方差；每次从同窗重新计算 | 固定平台的同一空间假设，重复相关帧不作独立后验概率累积 |
| F5 / T1 | 植被类别/认证 ROI 和校准射线关系缺失，F5 NOT_EVALUATED。移动序列的可信变换或同域连续背景未达到此实现准入，前后补偿对照及位姿扰动 UNAVAILABLE | 不把未标点当灌木；不建立烟幕内目标跟踪。本次只以小型非共轴旋转/平移数值例子校核坐标公式 |

## 等预算对照

S、T2=S+F0、TK=S+F1+F2+F3、TK_F4、TK_REC、TF、MASK（仅历史质量）、ACC（同一真实历史**完全相等点数**的无序体素累计）、COPY（当前帧逐字复制相同窗口长度）、SHUFFLE（仅打乱过去窗口内部）、DISTANT（同一事件与划分中更早的等长度历史）、TK3（最后三帧）、LAG2 和 LAG4 各自重新拟合。T2 为 lag1；TF/TK 的最大窗口为 9。COPY 和真实历史的帧数相同，各帧实际点数可能不同，故另报告 raw point budget，用 ACC 检验相等真实点数。DISTANT 因没有足够早帧可不可用。所有时序模型在相应点不可用时逐值返回同种子的 S 分数。报告严格相交的可用分母和全帧回退分母；仅在非空交集内才可比较包含 DISTANT 的结果。

唯一探针为线性 logit，标准化均值/标准差和正类权重 sqrt(n_non/n_dust) 仅在该种子训练点拟合；标准化值裁剪到 ±8。固定 CUDA AdamW，48 次真实全训练样本遍历，batch=4096，lr=0.012，weight_decay=0.01；线性头统一从零初始化，与种子有关的是训练点选择和 batch 顺序。测试不参与特征标准化、拟合、选轮或阈值。命令运行后各模型保存原生 weight、bias、均值与尺度（线性头可直接重算，不需 pickle），每轮曲线、拟合耗时、训练点 SHA、每中心监督来源。

RandLA N1 共用同一八个标量：F0 最近邻模长、细和粗支持、F2 平移残差、F3 稳定核心、F4 平滑留出增益、REC 加权支持、可用性；不提供方向性坐标矢量作为增强通道。缺史提供 0 并保留不可用掩码。网络接入时使用这些点的原行顺序；没有原束标签或逐点时钟。

## 运行与输出

已绑定源码快照的 197 容器内：

```bash
python -B probes.py --manifest manifest.json --out "$LIDAR_RUN_DIR" --seed 197
python -B probes.py --manifest manifest.json --out "$LIDAR_RUN_DIR" --seed 241
python -B probes.py --manifest manifest.json --out "$LIDAR_RUN_DIR" --seed 3090
```

先完成首个种子，之后再运行另两种子。默认缓存位置为任务目录中的 cache/组合SHA/，缓存绑定当前协议、特征、loader 和探针代码；若先用 --stage cache，则只会计算并存储特征，不训练。weights/seed/training.json、scores/seed/中心UID.npz（含原索引、scope、可用性、S 和各对照分数）、run_seed_*.json 为完成证据。未生成这些收据的分支必须列为未执行或失败。对显存、算时和效果的解释以真实对应运行记录为准。
