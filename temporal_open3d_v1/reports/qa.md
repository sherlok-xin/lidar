# 独立评价复核

对象是**离线研究输出与操作点**。QA 不认证材料身份、事件独立性、完整原生 Open3D pipeline 或车辆通行安全。此执行线程曾编写数据适配器，因此不把它对该适配器的静态检查记作独立数据审计。评价复算使用另写的读取器与计算式，未调用项目 evaluate、训练代码或 scikit-learn 指标。

- 按发布目录自身哈希及 release.json 逐文件验证；正式运行对应同一个 444 中心清单。检查 38/10/10 公开整录制角色、所有场景内历史和较远负对照；索引自独立 NPY/RAW PLY 二进制解码。POST-LIO 来源标签用原始 original_index 字典连接，未使用坐标邻近或模型输出生成参考。按身份和语义去除 0/4/冲突/未预测，0类 UCHILE 显式映为尘。
- 上游固定 commit 的 RandLA 代码含5个 forward 实现；与实际导入的兼容图比对，5个 AST 全等，许可证相同。训练用兼容图和自有采样/投票管线；不将其称原生框架或论文性能复现。48次 tinyfit CE 从0.58286降至0.12352，但该 patch 非尘4092/尘4，下降不证明尘类充分学习。独立读取37,914行探针分数核实按原始行恢复、正质量和归一化。
- 只把非测试验证录制的完整帧宏 AP 用于选 checkpoint。真实检查两帧另一个GPU进程重载所得 NPZ 各键与原输出逐值相等。未另行训练。N1 内部 checkpoint 选择在合资格 T0 帧上用 N1 本身；面向最终使用时，时序不可比的点替换成 N0 分数。两种 AP 有不同含义。
- AP 使用按实际分数并列组累积的阶梯积分，梯形 PR-AUC 独立计算；缺正类的 AP 置空。风险策略只用行人事件 validation 的 5,244 尘、4,094 行人（12帧）、29,219 车（11帧）；按两个实体各≤1%与尘召回≥10%的约束，用按阈值独立二分计数复算。无阈值不可行不会写成安全。
- 来源参考覆盖稀疏：本地行人评价有4,155个行人点、无车；跟车评价有10,665个车辆点、无人。报告行为和误抑制分子/分母；不把忽略区未过滤计TN。公开 non-dust 不等于人/车。真实植被缺独立标签。

本地未发布的机器收据 `qa.json` 保留已完成的具体模型、工作点和逐录制事件指标，不以任务排队或 checkpoint 出现作为评价完成依据。复核入口 `python3 -B tests/qa_eval.py --help`。

## 完成的复算与结论

判定：**通过的范围是冻结协议上的探索性学习实验及其评价复算。未证明实体保护、物理机制或未见会话安全性。**

1. 116个验证/评价中心共3,586,178行（含613,369忽略点）。8个网络及每个种子的4个主探针均有完整源行、原索引和源标签对照；网络正质量归一/无质量处理及N1全部缺时序原点到配对N0的回退都逐点验证。3个探针种子分别从328个训练中心选331,224点，按冻结种子独立恢复全部监督点身份摘要和类别权重；每个种子都只有4个本地训练车点。配对网络训练帧集合、网格、选模验证UID和相同轮数内的实际更新、类别贡献相等，公共训练轮数分别24/30/30。
2. 三个主评目录分别完成96/72/72个全录制工作点行（含AP、梯形PR-AUC、FP/FN、人车分母和ignore候选）的数值重算，合计240；另复核144个严格配对模型×录制的AP、168个对照×录制的分母及TF/对照AP。对所有50个配置/种子，逐一复算1,925,994个验证阈值及其三项计数和最终选择；没有一个配置满足本地双实体各≤1%且尘召回≥10%。197的S/TF另独立复算56项空间分层；未声称每个消融每个分层都独立重算。
3. 公共静态8录制共同1,135,123个可比有标点，三个种子平均事件宏AP：S **0.3761**、T2 **0.4867**、TK **0.7385**、TF **0.7657**、配对N0 **0.8325**、N1 **0.9172**。N1−N0平均+0.08465，三种子均正、按种子均值计7/8录制为正。TF比单帧、复制、简单累计和仅可用性输入更强；但在各自同点分母上，TF减乱序分别−0.0158/−0.0177/−0.0067，TF减更早非邻近历史−0.0877/−0.0833/−0.0814。支持静态背景历史特征存在判别信息，不能归因于有序短窗的真实刚体运动或尘的扩散。不能将探针消融当作额外神经网络乱序消融。
4. 行人评价12帧内有17个“同帧+标注实体ID”集合（4,155点，17组均≥10点）。197种子0.5阈值下，S/TF各有17组至少1点误抑、6组损失≥一半、0组全失；配对N0/N1为4、1、0；联合N0为13、11、**7组全部参考点被误抑**，共2,579/4,155点。实例ID不跨帧计轨迹，这些是来源标签组被破坏的反例，不是目标检测漏检率。`qa.json/ped_source_groups`列出每组分母与保留数。
5. 3个真实RViz案例共7,386条误判CSV与各自原帧XYZ/I、source ref、original_index、S/TF分数及错误类型逐点一致。复核中实际查看了已保存的三案例同视角拼图，另读取36个线验证与真实TTY控制回执；未另行启动ROS。完整 checkpoint 重载再推两帧合50,693行，所有数组与原推理逐值相等。两次从相同状态续一步的GPU参数最终摘要不相等，现有运行只能声明状态可载入及推理重现，**不可承诺续训逐位一致**。原生完整Open3D-ML管线在此环境未跑通，本轮训练的是固定上游RandLA-Net前向图及明确列出的适配层。
