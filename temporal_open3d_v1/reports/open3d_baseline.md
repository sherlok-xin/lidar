# 197 单卡 RandLA-Net：上游实现与本任务适配

本实验预测当前帧的粉尘来源标签。公开集 non-dust 没有人/车子类；本地为 POST-LIO 来源标签代理，不能当成材料认证或安全性能。无军事烟幕/战术目标数据训练或跟踪。公开 old test 沿用为录制留出，不宣称会话盲测。

## 上游与隔离

- Open3D-ML MIT，commit `a3d0f7a51d4eef0b94b9000a7d74af05e2d54c4f`，`ml3d/torch/models/randlanet.py` SHA256 `8d7d3457ed653a5ead2ffbdca01388bf95e3cd9b102aea19965dae743ff17839`。运行时逐字节核验，从本机固定检出生成每个 run 私有模块，检查实际模块路径。每个 run 的 `graph/compat.patch`、生成源码、许可证可以对照。上游正式 SemanticSegmentation 分布式分支拒绝运行。本轮均为单独单卡进程。
- `temporal_randla_checkpoint_qa197/native.json`：在 197 的新任务目录从只读快照临时副本离线安装官方 Python 源包，真正的 `ml3d.__file__` 位于 `native_target`，上游模型文件 SHA 相同。未适配原生包的模型导入首个缺失模块是 `addict`。另一次可选 Open3D CPU wheel 下载在 99.6 MB 文件下载阶段由本任务显式结束，exit143，未宣称 wheel 或原生扩展安装成功。原镜像及系统依赖不改动。
- 真正训练的是上游 RandLANet 的 encoder/decoder、随机子采样、局部特征聚合与 logits 的原计算图。兼容补丁只替换上游基类配置/随机数、移除数据管线导入与模型注册；原预处理/增强/loss/推理管线被新适配层替代，不调用悬空的上游方法。不能称未改官方完整管线，也不是复现 SemanticKITTI 成绩。镜像 ID 与 Python/Torch/CUDA 版本见各 `.job/<name>/launch.json`、`environment.json`。

## 测试前固定的训练与推理

- 发布快照 `3d644f0896362d0678d2`；点数 4,096/局部块，batch 4，16 邻居、4 级 4 倍子采样，上游宽度 [16,64,128,256]。检查 197 RTX 3090 上 48 次实际更新，训练集极小块非尘 4092、尘仅 4，CE 首 .583 末 .124；检查点重载最大差 0。测试帧不用于这一步。整帧 37,914 行，37,914 个有限输出；各步 .053 秒，整帧 .418 秒。仅验证链路和拟合能力，不能代表少数类性能。
- `N0 public` 用公开训练录制，`N0 joint` 用公开与行人训练时块。主 `pair N0/N1` 仅使用同一批 227 个有至少 3 个可比较滞后的 T0 训练中心和 32 个验证中心；测试 29 个同条件中心。每个监督预算为每中心每 epoch 一份局部邻域，按种子配对。其余帧另作全域/回退评价。N1 输入为 XYZI 加八个有来源的标量/可用性通道，N0 为 XYZI；空间坐标不做人工 RGB 增强或有方向矢量旋转。输入强度与时序特征标准化仅拟合本运行的训练帧。
- 网格边长由最多 12 个训练帧中的有限最近邻间隔中位数的一半决定，单位为数据的处理坐标。体素取坐标、特征均值和 0=ignore/1=非尘/2=尘多数票（并列优先较小码）；布尔通道均值为覆盖比例。各帧原类数、降采样类数、各原参考类回投标签差异输出 `voxels.json`。损失仅用合法、非重复填充槽；全 ignore 批跳过。负/正类别权重为训练体素频数逆平方根。Open3D 忽略值 0 不等于 UCHILE 原始 dust=0。
- 每真实 epoch 遍历当前训练清单；逐 epoch 唯一帧、各域有效点数、忽略点、更新数与耗时见 `epochs.jsonl`。最多 30 epoch，3 epoch 一次完整帧验证，按支持尘标签的录制宏 AP 选权重，4 次未改善提前停止。固定种子 197、241、3090。验证选权重时评估独立候选图，最终 N1 对不可比较的点按同种子配对 N0 回退，所以此处验证准则和最终混合策略应区分。完整状态包括当前及最好模型、优化器/调度器、训练 RNG、CUDA RNG、epoch 与代码/输入协议摘要；恢复时只接受匹配身份与前一 best。训练配置快照和图补丁随权重提供。
- 整帧按空间递归分片，真实邻域补足而不是造点；块内真实行仅计一次 EMA。随机顺序按 seed/UID 固定。取验证和测试输入有限行的最近体素回投；原行是 `original_index`，回投是分数插值，不冒充跨云精确对应。`predictions/{val,test}/<uid>.npz` 包含原 index、raw_scores、归一化 dust score、明确可预测 mask、时序可用性、code 和 ref。正质量才归一化，未预测分数 NaN，原 0/4/conflict 不算 TN。N0 的 temporal_available 恒假是模型不使用历史；成对分母须取相同帧及 N1 的实际可用掩码。
- 计算量归档：真实网络/分块KNN/回投总耗时、I/O、历史构建、体素预处理、GPU峰值见 `finished.json`；逐 epoch 训练与完整验证分别计。网络时间包含 patch 构建与投票，此项未独立拆分 GPU 核与回投微耗时。

## 核验及复现入口

`network_queue.py` 只提交预声明的 8 项实验，首对真实成功后才排重复种子。`network_export.py` 不训练，核验训练时的代码/清单/状态后可在新的 run 重推。`network_results.py` 按来源索引、分数正质量归一和留出事件宏 AP/F1 复核。两次本地功能测试验证无回波不打分、原槽覆盖、padding 不重复贡献损失与 ignore。

独立任务 `temporal_randla_checkpoint_qa197` 加载已选 `pair N0,197` 权重，在公共 30,090 行及本地 20,603 行上重推整帧；与原发布分数、mask、来源字段逐值相同。并非所有 8 组全部重新训练。

完整状态与**逐位复现续训**要分开：`temporal_randla_resume_qa197` 将真实第 24 轮状态加载两次，各执行一次同一个合法训练块。更新前权重/优化器摘要、下一采样索引、CE、调度器、学习率及 Python/NumPy/Torch/CUDA 四个随机数逐位相同；更新后权重/优化器摘要不同，严格逐位连续性检查失败，保留退出码 1 和原始断言。不能据此定位某个特定 CUDA 算子。相同最高 epoch/采样预算不保证实际已用训练步数相同：每个模型独立按预声明验证规则选优及早停。

后续 `temporal_randla_profile_r2_197/resume_check.json` 的独立测量：440 个权重/优化器张量的至少一个值不同，最大绝对差 0.00158743；两次 CE 均为 0.2522891164，源 epoch=24、恢复后的 scheduler=25。没有保存续训新模型。

冷启动分段计时案例：`temporal_randla_profile_r3_197/profile.json`，固定 T0 帧 `exterior1__Area_1__amtc_062`，30,090 行，8 个 patch。当前与历史读取 .0026/.0138 s，时序特征 .4071 s，体素化及建立回投表 .0523 s，加载模型 .2254 s，分片 .0208 s，构建 KNN 和组批 .1328 s，GPU/传输及 softmax .3905 s，投票 .0035 s，施加回投及归一化 .0017 s。30,059 个历史可比较行发布分数、原推理函数和分段结果完全逐值相同，另 31 个行按 N0 回退。单例没有平台运动补偿耗时，不是实时帧率。先前分段实现将模型构造也置于 inference_mode，和正式脚本上下文不同，严格比较曾失败（raw 最大绝对差 2.75e-5，保留 R2 日志）；以上 R3 与正式推理上下文对齐。

最终离线导出为逐点核对而统一执行图后再合并配对 N0 分数；全窗无历史时也产生过随后被弃用的 N1 中间值。这部分额外耗时已经包含在运行日志中，不将其冒充优化后的在线系统延迟。用完全同一验证阈值时，N1 在本地没有时序输入，输出和对应 N0 逐值相等。

实际降采样对照：joint N0 的训练原始 ignore / non-dust / dust 为 432,999 / 10,414,457 / 623,472；体素为 432,999 / 10,012,626 / 610,343。用最近体素类别回投原始行，原 dust 不同 35/623,472，原人 0/16,405，原车仅 0/4。这里的“不同”检查体素化引起的标签变化，不是模型误分类指标。车仅 4 个训练点，使得联合适配的实体结果必须特别谨慎。配对训练域则没有人车细类参考，原 dust=467,229、体素 dust=456,526，原尘回投不同 14。
