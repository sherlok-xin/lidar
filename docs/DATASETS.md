# 五层数据入口

源数据只读 → 本地目录和逐帧引用 → 普通单雷达读取器 → 按需缓存 → 少量三维预览。没有统一强制转换、建图或训练；相机不作为模型输入。完整私有索引和事件对应表在 DERIVED_ROOT 下，不公开采集路径或逐目标记录。

| 来源 | 原生格式/身份 | 训练资格和限制 |
|---|---|---|
| [UCHILE-Dust](https://github.com/nicolasCruzW21/UCHILE-Dust) | coord/intensity/segment 三组 NPY 同行；58个录制，14,161帧 | 发布者逐点标签。与论文公布14,117相差44，不删帧；按整录制角色切分并保留同源限制；静态可用帧序不等于有物理时间。 |
| [LiDARDustX](https://github.com/vincentweikey/LiDARDustX) | 22,562个 float32 Nx4 BIN、同槽 uint8 LABEL、独立3D框文件。1,307,884,405 存储槽，不等于有效点 | 六精细组7,562帧可作严格点监督，另三组共15,000帧映射待证。按序列/跨设备同源候选隔离，不能认证未见会话。有问题的框不否定逐点标签。 |
| 本地标注云 | PLY.original_index 精确连接对应的 POST-LIO 点；5包1,067帧，reviewed 和 v1/v2 不额外算事件 | 人、车和尘/烟代理，随来源状态和介质准入，静态边界不自动升为实体。不能迁到同场 RAW 云。 |
| PCD+框 | 来源分成9序列，33,857 PCD、29,103个JSON、74个空文件和31,633个框；类型字符串不是实体真值 | 普通民用序列提供框关联；其余涉及遮蔽场景的来源只做覆盖登记，不建立对象追踪、训练入口或独立认证。 |
| 多个目录下的 ROS1 bags | 索引、类型、话题和有界原始消息；算法结果不是人工真值 | 标准云及原始包各一段；保留时间/坐标/字段/索引证据。未完成可靠解码的其余 bag 只是库存或候选；不从文件名、目录名或表格认定标签。 |

新入口的具体实测行数、排除条件和逐源误差见 [hub 报告](dataset_hub_report.md)。[规范](DATA_SCHEMA.md) · [训练设计](NEXT_TRAINING_PLAN.md)。公开数据按发布者规定取得，第三方源码及权重按各自许可单独放置。需补全私有历史证据的步骤不能仅凭公开 checkout 运行。
