# 统一数据入口 V1 的实测范围

本地来源索引 `dataset_index.csv` 共 722 行，其中原生来源/序列 664 条、ROS1 文件 58 条。逐帧清单引用 42,048 条原生帧；另抽取两个真实 bag 窗口、共 6 帧。一个来源条目、一帧和一个物理事件是三个不同的计数单位。索引与实体数、帧数不可相加。来源本机路径在私有配置中解析；Git 中保存生成与核验代码。

**监督资格。** UCHILE 有 14,161 帧和 500,028,713 个有效发布点，34,251,801 个发布者粉尘点。DustX 六个编码明确的来源有 7,562 帧、472,768,551 个原存储槽，364,218,211 个几何有效，其中 34,212,254 个严格粉尘、329,599,838 个明确非尘、406,119 个有效但不计监督。另 15,000 帧有可读几何，编码仍待确认。本地 426 帧可在核准 POST-LIO 源索引上使用已有来源标签；已历史曝光的跟车 267 帧适于来源代理探索。普通道路 4,258 帧提供框关联，202 帧缺同名框。其全库几何有效点数待核。[逐源统计、去除的占位和来源角色](../datahub/native_data_report.md) · [编码表](../datahub/label_schema.yaml)

**划分和连续性。** 既有 UCHILE 划分保留。DustX 的候选划分以整段和可能共采的日期并组，异常时钟的两组 266 帧暂缓。原生检查遍历 42,048 条帧身份，检查 248 个公开来源划分组，并在 18 个真实读取条件下比较标签、源索引和有效掩码。三组 RAW 与 POST-LIO 来源通过既有录制 UID 与文件身份关联，跨处理域的点没有一对一标签映射。独立采集凭据不足的其他组保留未知；有帧序或里程计的移动来源尚未通过时空配准门。[帧结构与时间约定](DATA_SCHEMA.md)

| 实际抽取 | 连续消息序号 | 存储槽 | 有效点 | 实测范围 |
|---|---:|---:|---:|---|
| 标准 PointCloud2 | 0–2 | 432,000 | 309,970 | 从源消息复核声明字段、布局、整数时戳、索引及 binary PCD |
| RS128 原生包 | 3–5 | 691,200 | 312,331 | 1,800 个 MSOP 包，以真实 DIFOP 和固定版本驱动解码，独立重算高度最大差约 1.21 微米 |

两段都无逐点材料标签。RS128 所取逐包信封时间全零，嵌入设备时间与 ROS 帧头相差约 8 小时，不能据此校准时钟。遍历 58 份 bag 的文件头/页脚，57 份索引可读、1 份缺预期文件头；只有所取窗口做了载荷验证。[抽取代码、驱动版本与可复现检查](../bag_tools/README.md)

**模型与三维核验。** 在冻结 N0 的一个公开训练帧上，37,814 个有效原点映射到 36,633 个体素，再全部回到原行。GPU 上封存与公开入口的六项输出逐值一致。Noetic 独立订阅者核实五个图层；来源标签、原输入两张同视角原生 RViz 渲染已发布。此帧无 ignored 点，非空忽略层渲染仍缺实例。[收据、截图与 RViz 命令](../review_tools/README.md)

## 直接读取

从仓库根目录运行，先设置 DATA_ROOT、DERIVED_ROOT。首次生成时先运行两种来源的构建工具，传已有的本地证据配置，然后执行 compose。已有统一入口可直接读取。

```bash
python3 -B tools/hub.py list --dataset uchile
python3 -B tools/hub.py sample --dataset uchile
python3 -B tools/check_bag_samples.py
```

下一轮具备同一单帧主干按原点比较 UCHILE、明确编码 DustX、二者联合和固定本地预算的读取条件。本轮只验证一次训练样本前向及发布副本再现，新增设备的数据和实体误抑制仍需按冻结划分评价。[训练前应冻结的预算与准入条件](NEXT_TRAINING_PLAN.md)
