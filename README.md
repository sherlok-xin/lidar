# 单 LiDAR 粉尘识别：研究阅读版

本页与[六方法结果表](public_results.csv)可独立阅读。研究关注民用矿山点云：在地面尘雾中，能否利用历史回波区分粉尘与真实障碍物？输出研究的是点的来源标签，不是道路可通行性。

## 输入与对照

使用 [UCHILE-Dust](https://github.com/nicolasCruzW21/UCHILE-Dust) 的单雷达 XYZ 和强度及其派生特征，不用图像、速度或逐点运动真值。按完整录制划分，过去窗口不跨划分。静态数据只使用帧序，不把编号换成实测时间；历史不可比时退回同种子单帧模型。坐标相近不等于同一物理点。来源不明的运动缓存未用作监督。

- **S / T2**：S 是单帧强度与几何的线性分类探针；T2 增加到最近一个合格过去帧的近邻差分。
- **TK / TF**：TK 比较多尺度邻域支持、局部平移解释与结构保持；TF 再加入短窗衰减与受限平滑的观测特征。这些量不是颗粒速度或物理扩散系数。
- **N0 / N1**：用 [Open3D-ML 的固定 RandLA-Net 实现](https://github.com/isl-org/Open3D-ML/tree/a3d0f7a51d4eef0b94b9000a7d74af05e2d54c4f) 与适配后的数据、训练及整帧投票流程。N0 输入单帧；N1 在同一主干上增加历史观测和可用性通道。两者使用相同训练中心和监督预算上限；网络与线性探针跨族不是等预算架构消融。

## 实测结果如何读

在 8 个静态留出录制、29 个中心帧、1,135,123 个历史可比的当前有标点上逐点配对比较。CSV 的 macro_AP 先对每个录制计算粉尘平均精度再等权平均；pooled_F1_at_0.5 在共同点池上用固定阈值计算 F1；最后分别对三个固定种子取均值。三个种子不是三个新数据集。

N0 到 N1 的录制宏 AP 从 **0.8325 升至 0.9172**，三个种子的提升为 +0.0568、+0.1652、+0.0319，8 个录制有 7 个平均改善。排序改善不保证同一阈值下实体误抑制下降。

**对照揭示的限制：**在各自共同可用的原点上，TF 比等点数的简单历史累计高 0.3128 宏 AP，却比打乱过去帧顺序低 0.0134，比使用同录制较远历史低 0.0841。实验支持过去观测有信息，不能证明它来自有序尘粒运动。这是手工探针的对照，不是网络机制的直接验证。

静态矿山结果不能外推为移动设备表现。现有评价没有得到满足实体保护与有效粉尘召回双重要求的工作点，也没有认证植被材料或车辆安全。下一步优先补独立民用事件、可信的时间/坐标对齐及实体参考。

此公开仓库仅含阅读所需的方法、聚合结果与指标含义，不含逐点数据、内部采集记录、工程师源码或模型权重。
